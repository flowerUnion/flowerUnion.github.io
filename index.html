第一届秩序册

第一届花城中学生长跑接力联赛 秩序册

竞赛规程

  1. 集合
    1. 2026年2月8日上午7时40分，全体参赛选手需在广州地铁大学城南地铁站集合。
    2. 集合后进行点名并领取各校接力带。
    3. 无法准时到达的选手需要在赛事微信群内说明预计到达时间，或者向赛事负责人说明。
    4. 点名后合影留念。
    5. 合影后，奇数棒次（1、3、5）由大学城南地铁站出；偶数棒次（2、4、6）由大学城南搭地铁至大学城北站。
    6. 参加第一棒的男、女选手在志愿者带领下分别慢跑至相应出发区域。
  2. 比赛
    1. 上午8时30分整，男子、女子出发区同时发枪。
    2. 本校选手跑至距离交接点1km时，志愿者将进行唱名，下一棒次选手进入交接区等待交接。
    3. 交接
      1. 进入接力区前，前一棒次选手从身上取下欅带，在接力区域内传递给下一棒次选手。
      2. 欅带完成传递后，停止分段计时。
    4. 完赛
      1. 当一队伍的第六棒选手通过第一交接点则视作完赛，停止该队伍的计时。
    5. 特殊情况
      1. 选手如果突发身体不适，应立即告知志愿者骑手，并原地等待主办方车辆，根据情况严重程度决定是否送往医院。
      2. 若队伍有选手（因突发身体不适、受伤或紧急情况）无法完成比赛，则该选手的后一棒次（若有）在其他队伍完成交接后再出发。
      3. 若队伍中有选手退赛，则该队伍不参与最终总时长排名，但仍参与优秀运动员评选。
      4. 若选手退赛，该选手不参与优秀运动员评选。

运动员/志愿者详细流程

  1. 分组
    1. 骑行组
    2. 引导组
    3. 定点组
  2. 骑行组工作事宜
    1. 架设手机或与运动相机进行摄影；
    2. 一位骑手压尾，其他骑手机动拍摄；
    3. 第一位选手通过7km后于工作群中报告；
    4. 从工作群中接收队长喊话信息，向对应选手传达；
    5. 如遇突发状况需停止摄影，全力协助选手和主办方；
  3. 引导组工作事宜
    1. 在地铁站指引集合；
    2. 带领选手前往交接点/起跑点；
    3. 路口指引；
  4. 定点组工作事宜
    1. 在主、副交接点接应完赛选手和弃赛选手并提供饮料和食物；
    2. 看管参赛选手的个人物品；
